# 副业接单台 · 交付说明

**产物**：`副业接单台.html`（单文件，78 KB，双击即用，断网可打开）

## 四个模块

| 模块 | 内容 |
|---|---|
| 订单管理 | 客户、来源、类型、工作内容、报价、已收、待收、状态（洽谈/在做/待验收/已收款）、交付日期、收款到期日、实际耗时、备注；支持状态筛选 + 关键词搜索 |
| 收款看板 | 累计已收 / 待收合计 / 其中逾期 / 洽谈中金额；待收明细按应收日排序，逾期行整行浅红底 + 金额标红；已收记录单独列出 |
| 收入统计 | 近 6 个月收入柱状图（绿=已收，橙=待收，堆叠显示）+ 客户来源占比环形图（按成交金额）+ 月度明细表 |
| 时薪分析 | 各类型「报价时薪 vs 实收时薪」对比条形图、单笔时薪明细（含回款缩水百分比）、自动生成接单建议 |

## 首屏「今天要处理的」
自动汇总并标红：逾期未收款（显示逾期天数与金额）、今天要交付、交付已逾期；橙色提示即将交付（3 天内）、待验收超 3 天；蓝色提示待跟进报价。每条带一键操作：标记全额收款 / 转待验收 / 顺延到今天 / 编辑。逾期项永不消失，会一直顶在最上面。

## 数据与导出
- **自动保存**：任何增删改立即写入 localStorage（key `wb_sideorder_v1`），刷新关闭不丢
- **Excel 导出**：真正的 `.xlsx`（非 CSV 改名）。内置手写 CRC32 + ZIP(store) + OOXML 生成器，零外部库。含 3 个工作表：订单明细（带合计行）、月度统计（含回款率）、来源与时薪。金额列为 `¥#,##0.00` 数字格式可直接求和，欠款红字、已收绿字，首行冻结
- **JSON 备份**：导出全量备份；导入时可选「覆盖导入」或「追加合并」（按 id 去重），不限条数
- **清空示例**：只删示例单、保留自己录入的；若示例已清空则转为「清空全部」并二次确认
- 数据满 30 条时顶部温和提示导出备份

## 视觉与适配
浅色专业风（#f4f6f9 底 + 白卡片 + 蓝主色）。金额遵循国内习惯：欠款/逾期红色，收到的钱绿色，待收橙色，统一 ¥。PC 顶部 Tab + 表格；手机底部四宫格 Tab + 表格转卡片、按钮 ≥44px、输入框 16px（防 iOS 缩放）、适配 iPhone 底部安全区。全部图标与图表为内联 SVG 手写，无 emoji、无 CDN、无外部字体。

## 内置示例
7 条基于当前日期动态生成的订单（含 1 条逾期未收 ¥4,200、1 条今天交付、1 条洽谈中，以及跨 3 个月的历史已收单用于撑起图表）。
